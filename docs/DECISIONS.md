# REPARA - Decisions Log

## 23 August 2026

- The product addresses **Repair**, not Explanation alone.
- The primary user is a Mexico City delivery worker injured during an active order.
- The working slice covers report, fact verification, automatic repair, and bounded human escalation.
- Verification uses only existing platform data: GPS, timestamp, and order status.
- Shadow clause: report data and repair outcomes never affect rating, tenure, credit, or worker worth.
- The demonstration uses fictional data and labels every simulated AI result on screen.
- No personal data is stored. Therefore the working slice does not require authentication or a database.
- Human review is used only when automatic facts cannot resolve a case and must follow fixed criteria.
- Every case receives a visible fixed deadline so silence cannot act as denial.
